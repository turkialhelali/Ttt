# سُبحة

عدّاد أذكار واستغفار يعمل كتطبيق ويب (PWA) على الجوال، مع اهتزاز وصوت ووميض عند كل دورة وعند بلوغ الهدف اليومي.

- `index.html`: التطبيق كاملاً في ملف واحد.
- `sw.js`: يتيح العمل بدون إنترنت بعد أول فتح.

للإضافة إلى الشاشة الرئيسية في آيفون: افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
